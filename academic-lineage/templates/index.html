      公开数据导出

      只导出同时满足以下条件的数据：学者「公开」；关系「公开 + 已确认」且两端学者均公开。采用白名单字段，私有备注、草稿、拒绝记录不会出现在 JSON 中。

      导出后的发布步骤

      1. 检查 public/data/ 下生成的 people.json、relationships.json、manifest.json。
      2. 本地预览：python -m http.server 4173 --directory public 后打开 http://127.0.0.1:4173/。
      3. 人工检查确认后，将 public/data/ 提交到仓库，由 GitHub Pages 发布。
